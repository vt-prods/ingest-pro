# Ingest Pro Desktop for Windows

Ingest Pro turns a folder of multicamera footage into an editing-ready XML timeline for Adobe Premiere Pro or DaVinci Resolve.

This is the official release repository. The Windows installer is distributed through [GitHub Releases](https://github.com/vt-prods/ingest-pro/releases/latest); the application source code is not included here.

## What it does

- Detects and groups footage by camera from file metadata.
- Places every camera on its own video and audio tracks.
- Preserves the real recording time and gaps between clips.
- Synchronizes cameras by analysing their audio.
- Optionally applies camera colour labels and closes long inactive gaps.
- Exports an XML timeline for Premiere Pro or DaVinci Resolve without moving or transcoding the original media.

## Requirements

- Windows 10 or 11, 64-bit.
- 8 GB RAM minimum; 16 GB recommended for large shoots.
- Approximately 400 MB of free disk space.
- Adobe Premiere Pro or DaVinci Resolve to import the generated timeline.
- Internet connection for licence activation and periodic subscription validation.
